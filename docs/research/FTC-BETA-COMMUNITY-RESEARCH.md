# FTC beta community research — Facebook groups & Reddit

**Date:** 2026-08-26  
**Scope:** Melbourne / Naarm first; Mornington Peninsula → Victoria → Australia secondary.  
**Goal:** Find communities where a free FTC beta post could produce **real promoter trials on real events**, not impressions.  
**Method:** Public web discovery + mobile Facebook OG/title verification. No joins, posts, DMs, or logins.  
**Hard limit:** Facebook now walls most About/member/activity metadata without login. Counts and rules that could not be confirmed from public snippets are marked **UNVERIFIED**.

---

## How to read this doc

| Status | Meaning |
|--------|---------|
| **VERIFIED group** | Mobile Facebook returned an exact group title + stable group ID/URL. Existence confirmed. |
| **PARTIALLY VERIFIED** | Name + URL confirmed; member count / privacy / activity from a public snippet or secondary source only. |
| **SEARCH CANDIDATE** | Named in scene discussion or prior lists; **no public group URL confirmed in this pass**. Do not treat as real until you open it logged-in. |
| **NOT A GROUP** | Facebook Page, festival brand, venue, promoter org, forum, Discord, or Meetup — useful adjacency, not a Group. |

**Ranking criterion:** probability that someone in the community (a) runs or co-runs events, (b) books DJs, (c) would trial ops software on an upcoming night — **not** raw member count.

**Critical caveat (do not ignore):** cold posts in large punter/rave groups convert poorly for ops tools. Warm intros and “run one night with us” trials beat spray-and-pray. Use groups to **find** organisers; convert offline.

## First 5 communities to post in (execution plan)

Research only — **do not post until you are a member, have read current rules, and preferably asked admins**.

### 1) DJs in Melbourne  
**Post type:** Short “built for Melbourne club/warehouse nights” note from a local: problem = Sheets + IG DMs + group chats; free beta for promoters/DJs running a real upcoming event.  
**Link:** Direct link OK **if** rules allow; otherwise “comment LINK / DM me”. Prefer ask admins first.  
**Demo:** Yes — 20–40s screen recording of booking request → confirm → run sheet. Silent captions.  
**Tone:** Peer, not startup. No “disrupting nightlife.” Name genres/venues carefully without name-dropping unasked.  
**Goal:** Get 2–3 people who **have a date locked**.

### 2) MLB DNB – Melbourne Drum & Bass  
**Post type:** Scene-specific: “free tool for DnB night runners — lineup, fees, set times, crew chat.” Offer to onboard one upcoming night for free.  
**Link:** Prefer comment-on-request if group is anti-link; otherwise one link.  
**Demo:** Yes — run sheet + set times especially.  
**Tone:** Respect soundsystem/crew culture; no festival-ticket energy.

### 3) Melbourne Doofers  
**Post type:** Organiser-facing only. “If you’re running a doof/party and drowning in messenger threads, free beta.” Explicitly **not** a punter/ticket post.  
**Link:** Description already contemplates event ads — still check rules; tool posts ≠ event ads. Ask admin.  
**Demo:** Optional; screenshot of multi-DJ run sheet may land better than polished marketing.  
**Tone:** Community-first; avoid corporate language.

### 4) Melbourne Techno / House community  
**Post type:** Soft ask: “Looking for 5 techno/house promoters to trial free event ops tool on their next night.” Invite comments from people who **book DJs**.  
**Link:** Ask for comments first in large mixed groups (less spam-flag).  
**Demo:** Yes if allowed; keep under 30s.  
**Tone:** Quiet confidence; expect punters to ignore — that’s fine.

### 5) TECHNO/DEEP MELBOURNE *(or Melbourne Electronic Music if #5 is dead/hostile)*  
**Post type:** Same as #4, tighter genre.  
**Link / demo / tone:** Same playbook.  
**Fallback:** Melbourne House // Deep House… or Melbourne Techno if activity is better there.

### What not to do in the first wave
- Don’t lead with Mornington Peninsula groups (none verified). Use **MP Music Network** events instead.  
- Don’t spam r/melbourne or r/Beatmatch.  
- Don’t post the same copy into 10 groups same day.  
- Don’t treat Melbourne Techno Collective / Bunker / Technoir **Pages** as Groups — warm DM organisers instead.
