## How to use on a call

1. Show **Canva one-pager** (or PDF from HTML).  
2. Walk **screenshots 1 → 6** as the live loop.  
3. Soft ask: try one real night; Isaac sends invite.  
4. Do **not** promise payments, tickets, public launch, or Surreal-style venue/agency scope.
