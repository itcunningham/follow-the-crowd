About

Running events is messy.

Promoters and DJs currently juggle Instagram DMs, WhatsApp, Messenger, Notes, Google Sheets, email and calendars. Confirmations get lost. Set times drift. Nobody knows who’s pending, confirmed or declined.

Follow The Crowd (FTC) replaces that scattered workflow with one dedicated product — built for independent promoters, DJs and event crews. Not another social feed. Not corporate venue software. A calm, mobile-first tool for the work behind the night.

Respond Clear booking invites, accept / decline, and rate negotiation.
Coordinate DMs and crew chat tied to the event — not random group chats.
Execute Run sheets, calendars and status so the night stays organised.

What makes FTC different

  • The event owns the communication — booking → DM → crew chat → run sheet.
  • Built for independents — scene-native, not hospitality enterprise software.
  • Workflow first — Instagram stays discovery; FTC is where the work happens.
  • Mobile-first — designed for phones on the way to the venue, not just a desktop admin panel.

Private beta: FTC is live in production for coached early users. Payments, ticketing and public launch features are intentionally out of scope for this phase.

Who it’s for

Promoters / planners Create nights, invite DJs, track lineup status, coordinate crew, manage run sheets and calendars.
DJs / artists Incoming gigs, accept or decline, negotiate rates, message the promoter, see confirmed sets and history.
Event crews Shared crew chat once the lineup is locked — updates in one place instead of five group chats.
Not for (yet) Fans, ticket buyers, social feeds, or large venue / agency finance systems. Those come later — if ever justified.

Outcomes we aim for

  • Less chasing — pending / confirmed / declined is visible without digging through DMs.
  • Fewer dropped balls — rate, set time and lineup changes live with the event.
  • One night thread — crew chat opens when the booking crew is real.
  • Faster next event — the goal is promoters coming back without being reminded.
